# Mẫu email Supabase — InternChinese

Supabase → Authentication → Emails (Email Templates). Với mỗi loại: dán **Subject** và nội dung file HTML tương ứng.

| Loại (Supabase) | File | Subject |
|---|---|---|
| Confirm sign up | `confirm-signup.html` | 欢迎加入 InternChinese — Xác nhận email của bạn |
| Invite user | `invite.html` | 您被邀请 — Lời mời tham gia InternChinese |
| Magic link | `magic-link.html` | 登录链接 — Liên kết đăng nhập InternChinese |
| Change email address | `change-email.html` | 更换邮箱 — Xác nhận đổi email InternChinese |
| Reset password | `reset-password.html` | 重置密码 — Đặt lại mật khẩu InternChinese |
| Reauthentication | `reauthentication.html` | 验证码 — Mã xác thực InternChinese |
